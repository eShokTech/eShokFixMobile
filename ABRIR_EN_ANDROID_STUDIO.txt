eShokFix Mobile | Paquete listo para Android Studio

HAZ SOLAMENTE ESTO:

1) Descomprime el ZIP en una carpeta normal de tu PC.
2) Abre Android Studio.
3) Pulsa Open (Abrir) y selecciona la carpeta principal:
   eshokfix_mobile_rebuild
   IMPORTANTE: selecciona la carpeta donde ves pubspec.yaml y android.
   NO abras únicamente la carpeta android.
4) Espera a que Android Studio termine de cargar Flutter y descargar dependencias.
   La primera vez necesita Internet.
5) Conecta tu teléfono con depuración USB o selecciona un emulador.
6) Para probarla, pulsa el triángulo verde Run.
7) Para crear el APK: Build > Flutter > Build APK.

El APK de prueba queda en:
build\app\outputs\flutter-apk\app-debug.apk

Si Android Studio pregunta si debe instalar el plugin Flutter, acepta la instalación
 y reinicia Android Studio. Si pregunta por el Flutter SDK, selecciona la misma
 carpeta del SDK Flutter que ya utilizaste en tus proyectos anteriores.

Esta compilación es una beta local de laboratorio. Usa datos demostrativos y aún no
incluye sincronización con la PC, login comercial ni servidor real de licencias.
